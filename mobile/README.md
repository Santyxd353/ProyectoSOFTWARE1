# Aplicación móvil

Esta carpeta está reservada para la aplicación Flutter descrita en el PUDS.

## Alcance planificado

- Consulta y edición de proyectos UML desde el teléfono.
- Persistencia local de proyectos seleccionados.
- Cola durable de operaciones realizadas sin conexión.
- Sincronización y resolución asistida de conflictos.
- Chat por texto y dictado de voz.
- Reconocimiento y síntesis de voz ejecutables sin internet.
- Modelo compacto local para órdenes básicas y selección de funciones.
- Derivación a la IA en la nube cuando exista conexión y la solicitud sea compleja.

El código móvil se incorporará por iteraciones. Este archivo no declara la aplicación como implementada.
